## Моя рефлексия

С помощью библиотеки requests я реализовал GET-запросы к OMDb API и обработку полученных JSON-данных. Программа позволяет получать информацию о фильмах и выводить основные сведения о них. Некоторые трудности возникли при переключении между ветками и работе с изменениями: например, я не сохранил файл, и git status показывал «nothing to commit».

Для работы с зависимостями использовал виртуальное окружение .venv, чтобы библиотеки ставились только для этого проекта. В master ключ вводится вручную, а в ветке env-feature хранится в файле .env. Ключ нельзя оставлять в коде, потому что репозиторий публичный и им смогут воспользоваться посторонние, поэтому .env добавлен в .gitignore. В процессе работы использовал ветки Git: master хранит рабочую версию, а в отдельной ветке изменения можно пробовать без риска, поэтому movie-output-feature я объединил с master через Pull Request. Коммиты создавал после каждого законченного шага, чтобы можно было вернуться к рабочему состоянию. JSON — это текст вида «ключ: значение», который response.json() превращает в словарь, чтобы достать нужные поля через .get().

Из VS Code помогала строка состояния с названием ветки: по ней я проверял, куда попадёт коммит. ИИ-ассистент сделал code review и предложил обработать сетевые ошибки; я проверил правку на трёх случаях: существующий фильм, несуществующий и неверный ключ. В следующий раз делал бы коммиты мельче.

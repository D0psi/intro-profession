## Моя рефлексия

С помощью библиотеки requests я реализовал GET-запросы к OMDb API и обработку полученных JSON-данных. Программа позволяет получать информацию о фильмах и выводить основные сведения о них. Для работы с зависимостями использовал виртуальное окружение, а API-ключ хранил в отдельном файле .env. Также настроил .gitignore, чтобы не отправлять секретные данные и лишние файлы в репозиторий. В процессе работы использовал ветки Git, создавал коммиты, отправлял изменения на GitHub и объединял ветки через Pull Request. Некоторые трудности возникли при переключении между ветками и работе с изменениями. ИИ-ассистент помог проверить отдельные моменты и разобраться с возникавшими вопросами.

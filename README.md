# intro-profession

Практическая работа 1 по предмету «Введение в профессию».

## Описание
Ноутбук `rest_api_demo.ipynb` отправляет GET-запрос к OMDb API, получает ответ в формате JSON и выводит информацию о фильме.

## Запуск
1. Создайте виртуальное окружение: `python -m venv .venv`
2. Активируйте его.
3. Установите зависимости: `python -m pip install requests ipykernel`
4. Откройте `rest_api_demo.ipynb` в VS Code, выберите ядро `.venv` и выполните ячейки сверху вниз.
5. Получите API-ключ на https://www.omdbapi.com/apikey.aspx и введите его при запросе программы.

Не публикуйте API-ключи и файл `.env` в репозитории.

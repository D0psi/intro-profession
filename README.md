# intro-profession

Учебный репозиторий по курсу «Введение в профессию». Содержит практические работы по Git, REST API и работе с большими языковыми моделями через API.

## Состав проекта

### Практическая работа 1 — репозитории и интеграции

- `rest_api_demo.ipynb` — пример GET-запроса к OMDb API и обработки JSON.
- В `master` используется ручной ввод API-ключа.
- В `env-feature` ключ OMDb загружается из локального файла `.env` через `python-dotenv`; эта ветка остаётся отдельной.
- `movie-output-feature` содержит улучшение вывода информации о фильме; изменения этой ветки уже включены в `master`.

### Практическая работа 2 — работа с LLM через API

- `llm_work.ipynb` в `master` — базовое извлечение общего количества проживающих из 15 заявок варианта 20.
- Ветка `env-feature` также содержит `llm_demo.ipynb` — подготовительный пример подключения к GigaChat через API с загрузкой ключа из `.env`. Ветка не объединяется с `master`.
- Ветка `llm-improve-1` — обработка заявок в pandas DataFrame, сравнение ответов с эталонным количеством проживающих и расчёт точности. Результаты сохранены в `rental_with_results.csv`.
- Ветка `llm-improve-2` — расширенное извлечение полей в структурированный JSON, Few-shot prompting, ручная разметка и оценка точности. Ветка намеренно не объединяется с `master`.

## Подготовка окружения

Рекомендуется использовать Python 3.11 или новее. Если ранее ноутбуки запускались в старом окружении Python 3.9, создайте новое окружение на рекомендуемой версии и повторно выполните ноутбук: в старой сохранённой сессии встречалось предупреждение о LibreSSL.

1. Создайте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

2. Активируйте его на macOS или Linux:

   ```bash
   source .venv/bin/activate
   ```

   В Windows используйте:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

3. Установите зависимости из файла `requirements.txt`, который находится в соответствующей ветке:

   ```bash
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   ```

4. Для запуска ноутбуков в VS Code выберите ядро Python из окружения `.venv`.

## Переменные окружения

Создайте локальный файл `.env` в корне проекта. В нём можно указать ключи, которые используются в соответствующих ветках:

```dotenv
GIGA_KEY=ваш_ключ_GigaChat
OMDB_API_KEY=ваш_ключ_OMDb
```

Не добавляйте настоящий файл `.env` в Git и не публикуйте API-ключи. В основной версии `rest_api_demo.ipynb` ключ OMDb вводится вручную; переменная `OMDB_API_KEY` используется в ветке `env-feature`. Ноутбуки GigaChat используют переменную `GIGA_KEY`.
